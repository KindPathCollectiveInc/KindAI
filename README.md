# KindAI

KindAI is the consolidated home for the AI-Workbench product modules that were
previously restored as separate repositories.

This repo keeps the modules together so the public GitHub surface is easier to
understand and maintain. The old standalone repositories are retained as
archived recovery snapshots.

## Modules

- `modules/KiNDIS` - NDIS-oriented practice and coordination tooling
- `modules/KindBiz` - business support module
- `modules/KindCare` - care coordination module
- `modules/KindCreate` - creative practice module
- `modules/KindHealth` - health-oriented module
- `modules/KindHome` - household and home-field module
- `modules/KindLife` - life coordination module
- `modules/KindStudy` - study and learning module
- `modules/KindWork` - work and vocation module
- `modules/KindSocials` - communications and social publishing module
- `modules/KindCode` - local code/workbench interface module
- `modules/KindSearch` - search and hybrid retrieval pieces extracted from
  AI-Workbench

## Recovery Notes

These modules were consolidated from recovered Google Drive snapshots. Runtime
state, local databases, environment files, caches, and generated dependency
folders are intentionally excluded.
